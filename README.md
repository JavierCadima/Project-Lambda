# Project-Lambda
Project Lambda is a new SAC created in Brazil for educational purposes. It's open source, allowing users to update it according to their needs. By default, it includes Calculus I and II, such as Integrals, Limits, and Derivatives, plotting graphs, and much more. Feel free to use it. Developed by Javier Cadima.
